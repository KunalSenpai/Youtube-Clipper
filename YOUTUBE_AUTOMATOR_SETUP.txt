YT AUTO BOT - CONTEXT-AWARE SETUP

1. Install dependencies

cd "E:\YT Auto Bot"
.\venv\Scripts\python.exe -m pip install -r youtube_requirements.txt

2. Google Cloud / YouTube API

Open Google Cloud Console, create/select your project, enable YouTube Data API v3, and create OAuth 2.0 Desktop App credentials.

Download the OAuth JSON and rename it:

client_secret.json

Put it here:

E:\YT Auto Bot\client_secret.json

3. OAuth test user

If the Google OAuth app is in Testing mode, add the Google account that owns the YouTube channel under Google Auth Platform -> Audience -> Test users.

4. First upload

Keep this in youtube_automator.py:

PRIVACY_STATUS = "private"

The first run stores the authorization token here:

E:\YT Auto Bot\youtube_token.json

5. Normal workflow

Run:

.\venv\Scripts\python.exe main.py

Then:

.\venv\Scripts\python.exe youtube_automator.py

6. Full workflow

Newest local input video:

.\venv\Scripts\python.exe run_all.py local

Direct YouTube URL:

.\venv\Scripts\python.exe run_all.py "https://www.youtube.com/watch?v=VIDEO_ID"

7. Source / scene detection

The bot now attempts to identify the real-world source using:

- original yt-dlp metadata for YouTube URLs
- transcript quote searches
- optional OCR
- source/entity scoring
- season/episode pattern detection
- possible character detection

The result is saved as:

temp\source_context_<source_id>.json

8. Local videos

Optional sidecar:

input\clip.mp4.url.txt

Put the original URL in that file. This gives the detector a strong starting point.

9. OCR

pytesseract is included, but Windows also needs the Tesseract OCR executable for actual OCR. A common install location is:

C:\Program Files\Tesseract-OCR\tesseract.exe

If it is unavailable, OCR is skipped.

10. Automatic upload

Uploads are interactive by default.

For unattended upload confirmation, explicitly set:

$env:YT_AUTO_BOT_AUTO_UPLOAD="1"

Then run run_all.py.

Do not enable unattended uploads until you have checked the generated metadata and video.

11. Generated metadata

The uploader now saves:

temp\youtube_metadata_01.json

temp\youtube_metadata_02.json
...

These contain the detected source context used to generate the title, description and tags.

12. Rights

Source identification does not grant permission to reproduce copyrighted footage. Only process and publish footage you own or are authorized to use.


11. Scheduling

Default interval: 12 hours.

PowerShell:
$env:YT_AUTO_BOT_INTERVAL_HOURS="12"

The newest pending Short is PUBLIC immediately. Earlier pending Shorts are PRIVATE until their scheduled publishAt time.
