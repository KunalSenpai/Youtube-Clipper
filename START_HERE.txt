YT AUTO BOT — FINAL PACKAGE

1. Open PowerShell in this folder.
2. Make sure your Python venv and FFmpeg are installed as described in README.md.
3. If you already have your working bot folders (input/output/cache/config), copy your existing data into this project carefully.
4. Copy config/accounts.example.json to config/accounts.json and edit account names/token files/upload logs.
5. Keep client_secret.json and OAuth token files private; they are NOT included in this ZIP.
6. Start the dashboard:
   .\venv\Scripts\python.exe dashboard.py
7. Open http://127.0.0.1:8765

The dashboard controls YouTube uploads. Instagram is shown in the UI but is not wired for real publishing in this package.

Only process/publish videos you own or are licensed/authorized to use.
